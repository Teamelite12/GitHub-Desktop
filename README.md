# GitHub-Desktop

This is a **test repository** used for testing the [GitHub Desktop](https://desktop.github.com/) application on **Mac** and **Win32**, with a focus on **accessibility testing**.

## Purpose

- Validate GitHub Desktop functionality across platforms (macOS and Windows).
- Test accessibility features (screen readers, keyboard navigation, focus handling, etc.).
- Serve as a sandbox for experimenting with commits, branches, and pull requests.

## Notes

This repository does not contain a production application — it exists solely for testing purposes.
