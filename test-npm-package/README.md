# teamelite12-github-desktop-test-package-placeholder

Minimal publishable npm test package.

> Replace `teamelite12-github-desktop-test-package-placeholder` with your own **globally unique** npm package name before publishing.

## Install

```bash
npm install teamelite12-github-desktop-test-package-placeholder
```

## Usage

```js
const greeting = require('teamelite12-github-desktop-test-package-placeholder');

console.log(greeting()); // Hello, world!
```

## Local testing

```bash
npm test
```

## Preview package contents

```bash
npm pack --dry-run
```

## Publish

```bash
npm login
npm publish --access public
```
